# public/monsters

Drop the generated monster PNGs here. Filenames must match `MONSTER_IMAGES` in
`src/components/ui/monster.tsx`.

**Required (app states):**
`idle.png` · `listening.png` · `thinking.png` · `asking.png` · `happy.png` · `concerned.png`

Generate them with the prompts in `/monster-prompts.md`. Transparent PNG, square,
1024×1024, same character/palette across all six.
